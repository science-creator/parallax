# 📐 연주시차 실험실

중학교 3학년 과학 「별과 우주」 — **연주시차로 별까지의 거리 구하기**.
성취기준 **[9과23-01]** (2015 개정), 소단원 **(1) 별은 얼마나 멀리 있을까?**

## 어떻게 여나

**설치할 것이 없습니다.** `index.html` 을 더블클릭하면 바로 열립니다.

| 화면 | 파일 | 하는 일 |
|---|---|---|

| 📝 학습지 | `worksheet.html` | 24문항을 풀고 PDF 로 제출한다 (19문항 자동 채점) · 종이로도 뽑을 수 있다 |
| 🗂️ 선생님용 | `teacher.html` | 학생이 낸 PDF 를 파일 이름만 읽어 제출 현황으로 정리한다 |

## 무엇을 보여 주나

- **👀 책상 위 시차** — 선생님과 만든 <b>시차 측정 활동지</b>를 화면에 옮겼습니다.
  뒤에 숫자표(1~20), 앞에 구멍 두 개. 구멍을 바꿔 보면 별이 **다른 숫자**와 겹칩니다.
- **🌍 연주시차** — 1월과 7월, 두 자리를 **겹쳐 그립니다.**
  ∠ASB 가 통째로 보이고, 그 **절반**이 연주시차라는 것이 눈에 들어옵니다.
- **📏 연주시차와 거리** — `거리(pc) = 1 ÷ 연주시차(″)`.
  실제 별들을 곡선 위에 얹어 두었습니다.

## 이 앱이 남기고 싶은 한 문장

> **책상 위에서 구멍 사이를 벌리는 것과, 지구 대신 목성에서 재는 것은 같은 이야기다.**
> 둘 다 **기선을 길게** 만드는 것이고, 기선이 길수록 시차가 크게 측정된다.

미션 3에서 구멍을 벌려 보고, 미션 6에서 목성 궤도로 재 보면 바로 이어집니다.

## 미션 6개

1. 👀 시차를 만들어라 · 2. 📏 멀리 두면? · 3. ↔️ 구멍을 벌리면
4. 🌍 연주시차는 절반 · 5. 🔢 1 나누기 연주시차 · 6. 🪐 목성에서 재면?
